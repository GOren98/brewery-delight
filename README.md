# Brewery Delight

MVP addon for Farmer's Delight on Minecraft 1.21.1 / NeoForge.

## MVP
- Cooking Pot test recipe: water bucket + 4 wheat -> 4 Test Brew Base bottles
- Small Barrel multiblock: 8 wooden stairs + a sign whose first line is `Barrel`
- 9-slot non-stacking brew inventory
- 30 seconds fermentation -> Test Brew
- +1 aging star every 10 seconds, max 5
- Aged bottles use enchantment glint

The first release is intentionally a mechanics test build.
